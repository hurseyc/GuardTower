# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers and keep discussions focused on the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through a GitHub security advisory or by contacting the repository owner. Reports are handled confidentially.
